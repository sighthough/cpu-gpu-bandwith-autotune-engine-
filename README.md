# cpu-gpu-bandwith-autotune-engine-
this is a benchmark that measures your pc's cpu and gpu bandwiths over different chunks and provides a json file you can use in your project to set the optimal sizes for each

*Co-authored by [sighthough](https://youtu.be/UtPiUGwu-0Q) and Gemini 3.6*

How This Works Universally Across SystemsDynamic Metric Evaluation:
When any computer runs this HTML benchmark, the script iterates through buffer sizes and calculates the ratio:$$\text{Cost Ratio} = \frac{\text{Measured Latency (ms)}}{\text{Measured Bandwidth (GB/s)}}$$
It identifies the exact minimum ratio for Low-Latency applications and the true inflection point for Bulk Throughput
on that specific GPU and CPU architecture.JSON Hardware 
Profile Export:
Upon completion, clicking Export System Config (JSON) downloads gpu_memory_config.json. 
Any game engine, web app, or native C++/Rust software can read this file on boot to configure its allocation chunk sizes dynamically.

Here is a PowerShell script to restore your Windows OS settings, driver priorities, and power management back to standard Windows defaults.

### Part 1: Windows System Revert Script (PowerShell)

Run this in **PowerShell as Administrator** to undo all registry and power plan tweaks:

```powershell
# Run as Administrator in PowerShell
Write-Host "Reverting Windows System & GPU Settings to Factory Defaults..." -ForegroundColor Yellow

# 1. Reset Hardware-accelerated GPU Scheduling (HAGS) to Default (Disabled/Off)
$HagsPath = "HKLM:\SYSTEM\CurrentControlSet\Control\GraphicsDrivers"
Set-ItemProperty -Path $HagsPath -Name "HwSchMode" -Value 1 -Force
Write-Host "[+] Hardware-accelerated GPU Scheduling (HAGS) set back to Default (Off)." -ForegroundColor Cyan

# 2. Reset PCIe Link State Power Management to Default (Moderate Power Saving)
# Standard Windows Balanced plan default setting is 1 (Moderate Power Savings)
powercfg /setacvalueindex SCHEME_CURRENT SUB_PCIEXPRESS LINKSETTINGS 1
powercfg /setactive SCHEME_CURRENT
Write-Host "[+] PCIe Link Power Management restored to Default (Balanced)." -ForegroundColor Cyan

# 3. Restore DirectX / Driver Multimedia Task Priorities
$GpuPriorityPath = "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\Tasks\Games"
if (Test-Path $GpuPriorityPath) {
    Set-ItemProperty -Path $GpuPriorityPath -Name "GPU Priority" -Value 8 -Force
    Set-ItemProperty -Path $GpuPriorityPath -Name "Priority" -Value 2 -Force
    Set-ItemProperty -Path $GpuPriorityPath -Name "Scheduling Category" -Value "Medium" -Force
    Write-Host "[+] DirectX/Driver Multimedia task priorities restored to Windows defaults." -ForegroundColor Cyan
}

Write-Host "`nSystem settings reverted successfully! Restart Windows to apply changes." -ForegroundColor Green

```

### Part 2: Software Config Reset Method (JavaScript)

If your app or game engine reads a custom `gpu_memory_config.json` profile, add this `resetToDefaults()` method to your allocator class to fall back to safe standard engine defaults whenever a custom benchmark config file is missing or deleted:

```javascript
class GPUBufferConfigurator {
    // Safe standard fallbacks (used when no benchmark profile exists)
    static DEFAULT_CONFIG = {
        cpuToGpuUploadBytes: 1 * 1024 * 1024,      // 1 MB standard upload
        gpuToCpuDownloadBytes: 16 * 1024 * 1024,   // 16 MB standard download
        cpuL3UploadBytes: 1 * 1024 * 1024,        // 1 MB standard L3 upload
        gpuToCpuL3DownloadBytes: 16 * 1024 * 1024  // 16 MB standard L3 download
    };

    constructor() {
        this.resetToDefaults();
    }

    /**
     * Resets allocation sizes back to safe factory defaults.
     */
    resetToDefaults() {
        this.config = { ...GPUBufferConfigurator.DEFAULT_CONFIG };
        this.activeProfile = 'DEFAULT';
        console.log("Buffer configurator reset to default system values.");
    }

    /**
     * Loads dynamic config generated by the HTML Benchmark exporter.
     */
    loadBenchmarkConfig(jsonConfig) {
        if (!jsonConfig || !jsonConfig.optimalBufferSizes) {
            console.warn("Invalid config payload. Reverting to defaults.");
            this.resetToDefaults();
            return;
        }

        const lowLat = jsonConfig.optimalBufferSizes.lowLatencyProfileBytes;
        this.config = {
            cpuToGpuUploadBytes: lowLat.cpuToGpuUpload,
            gpuToCpuDownloadBytes: lowLat.gpuToCpuDownload,
            cpuL3UploadBytes: lowLat.cpuL3Upload,
            gpuToCpuL3DownloadBytes: lowLat.gpuToCpuL3Download
        };
        this.activeProfile = 'AUTO_TUNED';
    }
}

```
